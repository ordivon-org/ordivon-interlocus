# Foundation Architecture

The canonical architecture is a typed responsibility graph:

1. Capability Core — repaired NDF0 InterLocusCapability.
2. Composition Core — repaired NDF1 Inter-Locus Capability Composition / Realization Algebra.
3. Structural — NDF2 Structural Projection / Interaction Geometry.
4. Service — NDF3 Demand / Work / Service / Satisfaction & Transformation.
5. Resolution — NDF4 Reference / Naming / Binding / Resolution & Discovery.
6. Forwarding — NDF5 Forwarding / Reachability Realization / Routing-State & Convergence.

No edge implies a mandatory NDF0→NDF1→...→NDF5 pipeline. NDF5 is a specialization, not a universal realization gate.
