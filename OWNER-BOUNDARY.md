# Interlocus Owner Boundary

**Interlocus** owns Interlocus-specific projections/laws for exposed **cross-locus operational capabilities** and the interfaces/relations that require, offer, discover, resolve, bind, compose, realize, migrate, maintain or judge them.

The canonical referent is **Interlocus Capability**. The durable owner identity remains `research-owner:network`; `Network` is the historical project name and conventional networking is a specialization.

Imports / external owners:
- World: underlying loci, entities, resources, physics, state, generic observation reality.
- Runtime / Computing: execution, jobs, computation, remote-execution semantics.
- Harness / Host: Agent/tool coordination, planning, role, work continuity and organizational semantics.
- SCD: computational-description semantic predicates/meaning where imported.
- Computational Possibility: regime-relative achievability, methods/witnesses and computational limits.
- Normative: permission, legitimacy, jurisdiction, normative power and context-relative normative standing.
- Security / probability / information theory / control / statistics: generic mathematics and domain semantics external to Interlocus.

Classical packet/IP/host/layer-stack vocabulary is derived engineering/specialization vocabulary only.
