# Owner Boundary

Network owns Network-specific projections/laws for exposed cross-locus operational capabilities and the interfaces that realize, compose, structure, resolve, or forward them.

Imports / external owners:
- World: underlying loci, entities, resources, physics, state, generic observation reality.
- Runtime / Computing: execution, jobs, computation, remote-execution semantics.
- Harness / Host: Agent/tool coordination, planning, role, work continuity and organizational semantics.
- SCD: computational-description semantic predicates/meaning where imported.
- Security / probability / information theory / control / statistics: generic mathematics and domain semantics external to Network.

Classical packet/IP/host/layer-stack vocabulary is derived engineering vocabulary only.
