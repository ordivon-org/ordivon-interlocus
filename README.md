# Network Research Core

Network is the semantic owner of qualified **cross-locus capability, composition/realization, structural interaction projection, service/satisfaction, reference-resolution, and forwarding/reachability realization** semantics where those semantics apply.

It is not the ontology of packets, hosts, IP, links, routing tables, graph topology, execution, computation, Agent coordination, or computational-description meaning.

Current registry: **NDF0–NDF5 frozen at the current evidence frontier; NDF6 NOT ADMITTED.**

Whole-Network status: strong provisional domain closure; exhaustive closure is **not established**.

Architecture is a typed responsibility graph, not a mandatory numbered protocol stack.
